# Notes Adda

Notes Adda is a student-focused notes sharing platform built for WordPress. It gives students one simple place to discover, upload, organise, and share study material.

Users can create accounts, browse notes by subject, search the library, upload PDF notes, add tags, like useful resources, and manage the notes they have published. The interface is designed as a clean, responsive study library that works across desktop and mobile screens.

## Core features

- Student sign-up and sign-in
- Searchable library with subject filters and sorting
- PDF note uploads through the WordPress Media Library
- Tags, likes, reports, note previews, and note management
- Responsive workspace for browsing shared material and managing personal uploads
